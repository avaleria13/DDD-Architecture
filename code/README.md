# FixIt — Software Engineering II prototype
Python 3.10+, standard library only. Run `python -m unittest -v` from this directory. The lifecycle test is an executable demonstration. SupportTicket is the aggregate root; TicketId and Event are frozen value objects; TicketRepository is a persistence port; MemoryTicketRepository is an in-memory adapter; ConversationPolicy is a domain service; ClaimTicket coordinates the use case. Actor represents a trusted identity supplied by Auth, not a login mechanism. The prototype demonstrates a selected core slice, not the integrated web product. It omits account provisioning, actual chat persistence, attachment handling, ticket editing, catalog validation, HTTP, broker, and durable storage. Python private attributes are conventional, not a security boundary. The in-memory version check is process-local. No repository changes were made. See the report and diagrams for strategic design.
